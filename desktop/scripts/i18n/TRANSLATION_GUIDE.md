# Перевод интерфейса Buzz Desktop на русский

Buzz — корпоративный мессенджер (как Slack) на протоколе Nostr: сообщества, каналы, личные сообщения, треды, созвоны, ИИ-агенты. Пользователи — сотрудники российской инженерной компании (промышленная робототехника), не программисты. Перевод должен звучать как нормальный русский интерфейс (Telegram/Slack по-русски), коротко, без канцелярита.

## Формат входа и выхода

Вход: файл, одна английская строка интерфейса на строку. Строки извлечены из JSX, поэтому бывают фрагменты (", and", ". You can change this anytime.", "(optional)") — это куски предложения между элементами. Переводи фрагмент так, чтобы он встал на то же место (сохраняй ведущую/хвостовую пунктуацию и пробельную структуру).

Выход: файл TSV в UTF-8, ровно столько же строк, в том же порядке: `<английский оригинал без изменений>\t<русский перевод>`. Оригинал копируй байт-в-байт (включая &apos; &quot; &gt; и т.п.). В переводе НЕ используй символ табуляции и перевод строки.

## Правила

- `{}` — плейсхолдер (подставляется число/имя). Сохрани ровно столько же `{}` в переводе, в нужном порядке по смыслу. Не добавляй и не убирай.
- HTML-сущности в оригинале (&apos; &quot; &gt; &lt; &amp;) в переводе пиши обычными символами (' " > < &).
- Если строка не является текстом интерфейса (код, CSS-класс, идентификатор, формат даты, имя переменной, пример команды, путь, JSON-ключ, токен вроде KEY, ACP:) — выведи её без изменений в обе колонки.
- Не переводи: Buzz, Nostr, npub, nsec, ACP, MCP, CLI, JSON, URL, API, SSH, Git, GitHub, названия моделей и провайдеров (Claude, Codex, Goose, OpenAI…), клавиши (Cmd, Ctrl, Shift, Enter, Esc).
- Эмодзи и спецсимволы (⚠ 🎧 · — …) сохраняй.
- Кнопки — глагол в инфинитиве или повелительном («Сохранить», «Отмена», «Присоединиться»). Процессы с многоточием: «Joining…» → «Подключение…».
- Числа + единицы: «7 days» → «7 дней», «1 hour» → «1 час», «3 uses» → «3 использования».
- Обращение к пользователю на «вы» (со строчной).
- Капитализация как в русском: только первое слово с заглавной («Keyboard shortcuts» → «Горячие клавиши»). Если оригинал КАПСОМ (заголовок-лейбл) — тоже капсом.

## Глоссарий (держись строго)

community — сообщество; channel — канал; direct message / DM — личные сообщения (кнопка/раздел), личка (разговорно не используй); thread — тред; reply — ответ / ответить; mention — упоминание; reaction — реакция; huddle — созвон; join huddle — подключиться к созвону; member — участник; invite — приглашение / пригласить; agent — агент; persona — персона; team (агентов) — команда; harness — среда запуска; workflow — сценарий; relay — сервер (relay); identity — учётная запись (в смысле ключей — «ключи учётной записи»); keypair — пара ключей; profile — профиль; settings — настройки; notifications — уведомления; inbox — входящие; activity — активность; pulse — пульс; canvas — холст; forum — форум; post (форума) — пост; pin / pinned — закрепить / закреплено; archive — архив / архивировать; mute — без звука / отключить уведомления; unread — непрочитанные; draft — черновик; attachment — вложение; voice note — голосовое сообщение; status — статус; presence — присутствие (Online/Away — в сети / отошёл); allowlist — список разрешённых; memory (агента) — память; skill — навык; model — модель; backup — резервная копия; moderation — модерация; ban — бан / заблокировать; owner — владелец; admin — администратор; guest — гость; project — проект; repository — репозиторий; search — поиск; theme — тема; light/dark — светлая/тёмная; sidebar — боковая панель; home — главная.
